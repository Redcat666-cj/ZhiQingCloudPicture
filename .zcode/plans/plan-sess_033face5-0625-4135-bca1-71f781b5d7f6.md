# Spring AI 智能图库助手实施计划

## Context
用户要求在云图库项目（后端 D:\webai\zhiqin-picture-backend，前端 D:\webai\zhiqin-picture-frontend\zhiqin-picture-frontend）新增"右侧栏置顶 AI 助手"：点击悬浮球打开对话面板，用户用自然语言（标签/标题/描述）找照片。技术选型已定 **Spring AI**（1.1.5 GA，`spring-ai-starter-model-openai`，DashScope compatible-mode 复用现有百炼 key）。Spring AI 1.x 要求 Boot 3.4+ / JDK 17，项目当前 Boot 2.6.13 / Java 11，因此本计划 = 框架升级 + assistant 上下文 + 前端组件 + 端到端测试。用户已全权委托，自动多轮复查。

## Phase 1 — 升级 Boot 3.4 + JDK 17

1. **pom.xml**：`java.version`/compiler → 17；`spring-boot.version` → 3.4.x 最新；替换 starter：`mybatis-plus-spring-boot3-starter`(3.5.9)、`sa-token-spring-boot3-starter`(1.39.0)、`knife4j-openapi3-jakarta-spring-boot-starter`(4.5.0)；compiler-plugin 升 3.13.0；lombok 显式 1.18.44（本机 JDK 25 编译兼容）；新增 `spring-ai-bom:1.1.5` + `spring-ai-starter-model-openai`
2. **javax→jakarta**：36 个文件（`javax.servlet→jakarta.servlet`、`javax.annotation.Resource/PostConstruct/PreDestroy→jakarta.*`；javax.sql 不动，javax.validation 无）
3. **yml**（application.yml + application-local.yml）：`spring.redis→spring.data.redis`；删 `spring.session.store-type`、`server.reactive.session.*`；knife4j 旧分组配置改 springdoc 风格（包指向新 DDD 包）；新增 `spring.ai.openai`（base-url=https://dashscope.aliyuncs.com/compatible-mode、api-key 引 `${aliYunAi.apikey}`、model=qwen-plus）；`FileController` 的 `/test/downloads/` 去尾斜杠（Boot 3 不再宽容尾斜杠）
4. **修正**：`RedisConfig` 的 `@SpringBootConfiguration`→`@Configuration`；主类删除指向已删包的 `@MapperScan`；确认 `identity/domain/User implements Serializable`（Spring Session Redis 默认 JDK 序列化），缺则补
5. 验证：`mvn compile` 零错误 + `mvn test -Dtest=DddArchitectureTest` 通过

## Phase 2 — assistant 上下文（后端，遵守 ArchUnit 分层规则）

新建包 `com.zhiqin.zhiqinpicturebackend.assistant`：
- **interfaces**：`AssistantController`（`POST /assistant/chat` SSE 流式 + `DELETE /assistant/conversation` 清会话）、`dto/AssistantChatRequest`（sessionId+message）
- **application**：`ChatAppService`——编排 ChatClient（system prompt：图库助手角色+工具使用规则+不得编造）、`MessageWindowChatMemory`(20轮)、工具注册、SSE 发送（`delta` 文本增量 / `pictures` 图片卡片 / `done` / `error` 事件）
- **application/tools**：`PictureSearchTools` 四个 `@Tool`：`searchPictures(titleKeyword, tags, spaceId?)`、`getPictureDetail(pictureId)`、`listAccessibleSpaces()`、`listSpaceTags(spaceId)`
- **domain**：`PictureBrief` 值对象（id/name/thumbnailUrl/tags/category/spaceId，给模型+前端的最小结构）
- **infrastructure**：`RedisChatMemoryRepository`（实现 Spring AI `ChatMemoryRepository`，存自建 role/content DTO，只保留用户问题+最终回答）

**权限与线程模型（关键设计）**：@Tool 经 Spring AI `ToolContext` 携带 `userId` + pictures 收集器，**不依赖 HttpServletRequest/RequestContextHolder**（工具在模型调用线程执行）；权限判断复用 `SpacePermissionAppService.getPermissionList(space, user)`（不依赖请求）+ `SpaceMemberRepository.findBySpaceAndUser`；分表查询复用 `pictureTableRouter.inSpace()` 语义（经 `PictureRepository.page(PictureQuery)`）；公共图库强制 `reviewStatus=PASS` + `nullSpaceId=true`（与 PictureController 现有行为一致）；空间图库校验含 `PICTURE_VIEW` 权限才查。复用现有：`PictureAppService.pageByRequest`、`SpaceAppService.getById/listByIds`、`UserAppService.getById/getUserVo`、`PictureVO`。

## Phase 3 — 前端（Vue3 + AntD Vue）

1. `src/components/AiAssistantWidget.vue`：`a-float-button`（右侧偏上"置顶"位置）+ `a-drawer`(width≈420) 对话面板；登录/注册页隐藏（复用 BasicLayout 的路径判断）；消息气泡 + 图片网格卡片（thumbnailUrl??url，点击 router.push(`/picture/${id}`)，样式参照 HomePage 的 .picture-card）
